# Portable skills

This export includes one deliberately generic operating skill:

- [`operate-buzz-template`](operate-buzz-template/SKILL.md) describes a safe
  inventory-first workflow for a Buzz deployment.

Install it only after replacing the documented placeholders in a private copy.
It is not a deployment script and grants no privileges. OpenAI-managed system
skills and plugin caches are external dependencies and are not vendored here.
